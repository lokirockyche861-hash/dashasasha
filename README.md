# Интерактивный учебник по русскому языку (vue-render)

Образовательная веб-платформа с интерактивными уроками по русскому языку и алгоритмическими деревьями решений.

---

## Назначение проекта

Проект представляет собой интерактивный онлайн-учебник, состоящий из двух форматов обучения:
- **Теоретические уроки:** интерактивные лонгриды с богатым набором механик проверки знаний (`QuizSelect`, `FillInTheBlank`, `DragAndDrop`, `ClickWord` и др.).
- **Практические уроки:** отработка правил в виде интерактивного алгоритма (дерево решений, граф) с пошаговым выбором пути и итоговым вводом ответа.

В платформе заложен фундамент для психометрических расчетов (оценка сложности заданий, уровня учеников) и последующего внедрения адаптивных траекторий обучения.

---

## Технологический стек

- **Фреймворк:** [Nuxt 4](https://nuxt.com/) (`^4.4.8`)
- **UI-библиотека:** [Vue 3](https://vuejs.org/) (`^3.5.39`)
- **Сборщик:** [Vite 8](https://vitejs.dev/) (`^8.1.0`)
- **Серверная часть:** Nitro (встроенный серверный движок Nuxt)
- **База данных:** PostgreSQL ([Supabase](https://supabase.com/))
- **ORM:** [Drizzle ORM](https://orm.drizzle.team/) (`^0.45.1`)
- **Маркдаун-парсер:** `markdown-it` (`^14.1.0`)

## Быстрый старт

### Установка зависимостей
```bash
npm install
```

### Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### Сборка и предпросмотр
```bash
npm run build
npm run preview
```

### Проверка валидности уроков
```bash
node scripts/validate_lessons.js
```

## Структура папок проекта

- `/components` — Vue-компоненты интерфейса и интерактивные задания (`QuizSelect`, `FillInTheBlank`, `DragAndDrop`, `ActiveTree` и др.).
- `/composables` — Переиспользуемая логика (`useLessonProgress.ts` для управления состоянием прогресса).
- `/layouts` — Шаблоны страниц (`default.vue`, `GraphLayout.vue`).
- `/lessons` — Контент теоретических (`lessons/lesson*.json`) и практических (`lessons/practice/lesson-*.json`) уроков.
- `/pages` — Маршруты Nuxt (включая динамический роут уроков `pages/lesson/[id].vue`).
- `/public` и `/assets` — Статические ресурсы (изображения, стили).
- `/scripts` — Вспомогательные скрипты для миграций, экспорта и валидации.
- `/server` — Серверный слой Nitro: API эндпоинты (`/server/api`) и подключение к БД (`/server/db`).
- `/utils` — Утилиты и сервисы (включая `AnalyticsService.js`).
- `/референсы` — Локальные инструменты (в частности, SPA конструктор уроков `admin-panel.html`).
- `/.agents` — Настройки, правила и навыки для AI-ассистентов Antigravity.
