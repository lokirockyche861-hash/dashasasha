# Правила работы с файлами уроков (lessons/*.json)

При создании или редактировании файлов уроков в каталоге `lessons/`:

1. **Обязательные поля верхнего уровня:**
   Файл урока должен содержать:
   - `lesson_id` (string)
   - `lesson_version` (string, например `"v.1.0"`)
   - `topicId` (string)
   - `content` (array)
   - `schema` (string, например `"v1"`)

2. **Расположение кнопок управления:**
   Поля `button_text`, `button_next_text`, `button_finish_text` обязаны находиться **внутри** объекта `content` интерактивного узла, а не на верхнем уровне ноды.

3. **Обязательные поля интерактивных узлов:**
   Каждый интерактивный компонент обязан содержать:
   - `id`: уникальный идентификатор узла (по схеме `l{lesson}-n{nodeIndex}-{typeAbbr}-{salt}`)
   - `type`: зарегистрированный в `SimpleRenderer.vue` тип компонента
   - `skill_id`: идентификатор проверяемого навыка (не должен отсутствовать)
   - `answer_type`: тип логирования для аналитики (`select`, `input`, `match`, `multi-select`)
   - `taskVersion`: версия задания (например `"v.1.0"`)
   - `blocked`: boolean (по умолчанию `false`)

4. **Ссылки и контракты:**
   - Для всех опций и подзадач должны соблюдаться контракты схемы (подробно описаны в `docs/lesson-schema.md`).
   - Ссылки `correct_option`, `correct_group`, `next` должны указывать на существующие идентификаторы.

5. **Обязательная валидация:**
   После любого изменения файла урока необходимо запустить валидатор:
   `node scripts/validate_lessons.js`
