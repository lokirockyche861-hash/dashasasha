# Навык работы с практическими уроками (`decision-tree`)

> [!important]
> **Источник архитектурной истины:** [docs/decision-tree.md](docs/decision-tree.md). Все схемы данных, спецификации JSON и детали верстки брать строго из этого документа.

---

## 1. 4 Интерактивных архетипа уроков
1. **`SpineDecisionTree` (`layout: "spine"`):** линейный вертикальный каскад вопросов с боковыми терминалами (Уроки 1, 2, 11, 12, 14).
2. **`BinaryDecisionTree` (`layout: "binary"`):** разветвленные деревья решений, симметрии и многоуровневые каскады (Уроки 4, 5, 13).
3. **`StepAlgorithm` (`layout: "steps"`):** пошаговые процедурные чеклисты проверки слова чипсами без графа (Уроки 3, 7, 8, 9, 10).
4. **`MatrixClassifier` (`layout: "matrix"`):** многомерный категориальный классификатор (Урок 6, Фаза 4).

---

## 2. Операционные инварианты контента (Zero-Creativity Rule)
1. **100% верность теории:** Текст теории переносится 1:1 из `temp/Орфография/...md` (чистый Markdown). **Запрещено** добавлять интерактивные квизы внутрь теории практического урока.
2. **100% верность структуре:** Граф или чеклист обязан в точности повторять схему автора (`temp/картинки/граф_*.png`).
3. **Ориентация развилок:** Вариант **«Да»** всегда **слева**, вариант **«Нет»** — **справа**.
4. **Полнота упражнения:** Пул `tasks` формируется строго из Упражнения 1 автора в полном объёме с валидным `correct_path`.
5. **Контракт ввода:** Ученик всегда вводит в поле проверенное **слово целиком** (`correct_answers`).

---

## 3. Стандарты UI/UX и визуализации
* **Семантика цвета:** Нажатие «Нет» подсвечивается спокойным изумрудным (`#10B981`), если выбор верен. Красный (`#EF4444` + `shake`) — только при ошибке.
* **Капсула вердикта:** Вопросы — чисто-белые (`#FFFFFF`), карточки результатов — тонированные (`#F8FAFC`, высота `auto` ~50px).
* **Антиспойлер:** Из карточек результатов исключены примеры слов из упражнения; формулируется только краткая формула правила (например, *В суффиксе -ын-*).

---

## 4. Пошаговый чеклист создания урока
1. **Анализ:** Изучить `temp/Орфография/Урок <N>...md` и схему `temp/картинки/граф_<N>.png`.
2. **Создание автономного пакета:** Оформить `lessons/practice/lesson-<name>.json` (`id`, `title`, `topicId`, `theory`, `rule`, `tasks`). `rule.graphId` обязан быть уникальным.
3. **Регистрация:** Добавить запись в `lessons/index.js` (`isDecisionTree: true`, `archetype`, 4 лоадера).
4. **Проверка целостности:** Запустить `node scripts/validate_lessons.js` и сборку `NUXT_TELEMETRY_DISABLED=1 HOME=/tmp npm run build`.
