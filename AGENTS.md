# AGENTS.md — Инструкция для AI-ассистентов проекта vue-render

Добро пожаловать в проект интерактивного учебника по русскому языку.

## 1. Назначение проекта
Проект представляет собой интерактивную образовательную платформу, состоящую из двух типов уроков:
1. **Теоретические уроки (лонгриды)** — последовательность блоков (текст, Markdown, видео) и разнообразных интерактивных механик заданий (`QuizSelect`, `FillInTheBlank`, `DragAndDrop` и др.). Рендерятся через `SimpleRenderer.vue` на основе файлов `lessons/*.json`.
2. **Практические уроки (деревья решений / алгоритмы)** — алгоритмическая отработка правил в виде интерактивного графа (`ActiveTree.vue`) с финальным вводом ответа. Рендерятся через `DecisionTreeLesson.vue` на основе `lessons/graph.json` и `lessons/graph-task.json`.

В проекте заложена основа для психометрического анализа и адаптивного обучения: детальное логирование каждой попытки пользователя и надёжное восстановление прогресса.

---

## 2. Актуальный технологический стек
- **Фреймворк фронтенда:** Nuxt `^4.4.8` (Vue `^3.5.39`, Vite `^8.1.0`, Vue Router `^4.3.0`)
- **Серверный движок (Бэкенд):** Nitro в составе Nuxt (`/server/api`)
- **База данных:** PostgreSQL (Supabase / локальный Postgres)
- **ORM:** Drizzle ORM `^0.45.1` (схема в `server/db/schema.ts`, конфиг `drizzle.config.ts`)
- **Стилизация и рендеринг текста:** Tailwind / scoped CSS, `markdown-it` `^14.1.0`

## 4. Главные инварианты и правила
1. **Безопасность секретов:** Запрещено читать, выводить в чат или логировать файлы `.env`, токены, пароли и строки подключения к базе данных.
2. **Неизменяемость попыток (Immutability):** Таблица `attempts` хранит полную историю действий. Старые записи никогда не перезаписываются; каждое нажатие «Проверить» создает новую запись.
3. **Восстановление прогресса (Idempotency & Partial State):** При обновлении страницы интерфейс обязан восстанавливать последний введенный ответ (даже неверный или неполный), отображая результаты проверки (`showResults = true`).
4. **Контракт уроков:** Кнопки `button_text` всегда помещаются внутрь объекта `content`. Каждая интерактивная нода должна содержать валидные `type`, `id`, `skill_id`, `answer_type` и `taskVersion`.
5. **Валидация перед завершением задач:** После изменений в `lessons/` запускать валидатор уроков:
   ```bash
   node scripts/validate_lessons.js
   ```
6. **Git и деплой:** Не выполнять `git push` и не применять миграции к боевой базе данных без явного подтверждения пользователя.
